02 THE APPROACH

Verify the hidden steps

VeriRouter turns each hidden step into checkable evidence while keeping the router’s semantic index and rewrite banks private.

πsel

01 / CONTROL PLANE

Prove model eligibility.

A zero-knowledge proof checks HNSW semantic search over the committed index. Fresh turns establish eligibility; pinned turns reuse the accepted model.

Model selection
πrw

02 / DATA PLANE

Prove endorsed rewriting.

A rewrite proof preserves client messages and permits additions only from committed banks at allowed positions, without disclosing the added private content.

Request rewriting
σprovider

03 / SERVING BINDING

Authenticate the answer.

A provider-issued certificate binds the model, processed request, and returned response. The client checks the signature and its bindings to the same serving event.

Why these proofs are efficient

VeriRouter checks priority-queue and monotone-stack traces with a number of constraints linear in trace length. This avoids replaying every mutable queue state while proving semantic-search traversal. Read the construction ↗
